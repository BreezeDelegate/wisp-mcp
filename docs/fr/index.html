Étape zéro

Vérifie d’abord que ton panel est WISP.

Un hébergeur peut changer le logo, les couleurs et le domaine : les captures sont des repères visuels, pas une preuve absolue.

Ça te semble familier ?

Si ton interface ressemble à ces captures, ton hébergeur utilise probablement WISP. En cas de doute, demande : « Mon serveur utilise-t-il WISP et puis-je créer un token WISP Client API ? »

Si oui, aucune intégration propre à l’hébergeur n’est nécessaire.

Installation

Copie une commande.

Debian 12 et Ubuntu 24.04+ sont le chemin recommandé. Les secrets sont saisis de façon interactive et ne sont pas placés dans la ligne de commande.

N’importe quel client MCP

Installe uniquement Wisp MCP. Idéal pour Claude Code, un client MCP local, du stdio via SSH ou ton propre HTTP sécurisé.

curl -fsSL https://raw.githubusercontent.com/BreezeDelegate/wisp-mcp/main/install-vps.sh | sudo bash

ChatGPT

Installe Wisp MCP et l’assistant OpenAI Secure MCP Tunnel pour garder le MCP privé sur un VPS toujours allumé.

curl -fsSL https://raw.githubusercontent.com/BreezeDelegate/wisp-mcp/main/install-vps.sh | sudo bash -s -- --with-openai

Gros fichiers

Ne gaspille pas le contexte du modèle.

Les plugins et logs volumineux sont lus de façon ciblée. Une petite modification ne nécessite plus de réémettre tout le fichier.

Lecture ciblée

  • find_in_file renvoie seulement les extraits utiles
  • read_file_chunk borne la quantité de texte retournée
  • file_fingerprint donne SHA-256 et taille sans contenu
  • Les listes WISP sont paginées

Écritures protégées

  • replace_in_file pour un petit changement ciblé
  • safe_write_file pour un remplacement complet voulu
  • SHA-256 vérifié avant l’écriture
  • Contenu relu et vérifié après l’écriture
  • Les opérations destructrices restent séparées
