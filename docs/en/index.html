Always-on machine

Prepare a small Linux VPS.

Wisp MCP is lightweight and can run on a small machine. Your game server can stay with its current host; this VPS only runs the MCP and the private tunnel.

Terminal

Install Wisp MCP with one command.

The installer creates a dedicated system user, installs Wisp MCP and the OpenAI tunnel client, then asks for the panel URL and token directly in the terminal.

On your VPS
curl -fsSL https://raw.githubusercontent.com/BreezeDelegate/wisp-mcp/main/install-vps.sh | sudo bash -s -- --with-openai
  1. 1Paste the command and let the installer finish.
  2. 2Enter the WISP token only when the terminal asks for it.
  3. 3Continue only after the diagnostic prints Wisp API: OK.
Private tunnel

Now connect the VPS to ChatGPT.

The tunnel is outbound-only. You do not expose a public MCP port on the VPS.

  1. 1In OpenAI Platform, create or select an MCP Tunnel.
  2. 2Create a tunnel runtime key with the required Tunnels Read + Use permissions.
  3. 3On the VPS, run the command below and enter the tunnel ID and key only in the terminal.
  4. 4In ChatGPT developer mode, create the MCP app, choose Tunnel, scan the tools and save the app.
On your VPS
sudo wisp-mcp-openai-setup

AI routines

Add three Skills to keep the AI disciplined.

Copy each instruction into ChatGPT and ask it to create the Skill. They keep context in GitHub, make Wisp work safer and force every release to end with evidence.

Project Memory

Rules, roadmap, decisions and handoff stay versioned in the private repository.

Wisp Safe Ops

Inspect before changing, back up before risk, verify after each action.

Release Guard

Tests, live state, rollback and handoff before calling a batch complete.

These Skills are recommended, not required for Wisp MCP. You can create them later.
