WISP + Model Context Protocol

Donnez à ChatGPT les bons outils. Pas les clés de tout le serveur.

Wisp MCP relie votre panel WISP à ChatGPT ou à un autre client MCP. L’IA peut lire les logs, modifier une configuration, déployer un plugin, redémarrer un serveur ou créer une sauvegarde — uniquement avec les droits que vous activez.

Aucun token, mot de passe ou identifiant n’est demandé ici.

01

Un compte ChatGPT avec accès MCP

Utilisez le modèle le plus capable disponible. GPT-5.6 Sol est recommandé lorsqu’il est proposé ; sinon choisissez le meilleur modèle accessible sur votre offre. Pour un usage d’équipe ou intensif, une offre Business est recommandée.

02

GitHub, seulement si vous travaillez avec des dépôts

Connectez GitHub à ChatGPT si vous voulez que l’IA lise vos dépôts privés, garde une roadmap et documente vos règles. Wisp MCP lui-même fonctionne sans GitHub.

03

L’URL de votre panel WISP et un token Client API

Créez le token dans votre compte WISP. Ne le collez jamais dans un chat : l’installateur le demande dans un prompt masqué directement sur le VPS.

04

Un petit VPS Linux toujours allumé

Debian 12 ou Ubuntu 24.04+ est le chemin recommandé. Si votre MCP tourne déjà ailleurs, vous pouvez conserver votre infrastructure.

Onboarding guidé

De zéro à votre premier diagnostic.

Le parcours sépare volontairement l’accès WISP, l’installation du MCP et la connexion à l’IA. Une panne dans une couche ne vous oblige pas à refaire les autres.

ÉTAPE 01

Confirmez que votre hébergeur utilise WISP

Les panels WISP peuvent être white-label. Comparez votre interface à la capture plus bas ou demandez au support : « Mon serveur utilise-t-il WISP et puis-je créer un token WISP Client API ? »

Oui ? Continuez. Non ? Wisp MCP n’est pas le bon connecteur pour ce panel.
ÉTAPE 02

Préparez ChatGPT

Connectez-vous à ChatGPT et sélectionnez le modèle le plus capable disponible. Si GPT-5.6 Sol apparaît dans votre sélecteur, utilisez-le pour les tâches complexes de code et d’administration.

Ce site ne reçoit aucun accès à votre compte OpenAI. La vérification du modèle reste volontairement dans ChatGPT.
ÉTAPE 03

Connectez GitHub si vous voulez une mémoire de projet durable

Pour un serveur maintenu dans GitHub, utilisez un dépôt privé et conservez-y au minimum un AGENTS.md, une roadmap et un handoff. L’IA retrouve alors les règles, décisions et prochaines étapes au lieu de deviner.

Frontière : Git stocke la mémoire du projet ; Wisp MCP fournit l’accès au panel. Ne mettez jamais de token WISP dans Git.
ÉTAPE 04

Installez Wisp MCP et le tunnel ChatGPT

Connectez-vous au VPS puis lancez l’installateur. Il crée un utilisateur système dédié, garde les secrets hors Git et exécute un diagnostic avant de terminer.

curl -fsSL https://raw.githubusercontent.com/BreezeDelegate/wisp-mcp/main/install-vps.sh | sudo bash -s -- --with-openai
ÉTAPE 05

Commencez en lecture seule

Validez d’abord la connexion sans autoriser de changement. Ensuite, activez uniquement les familles d’actions dont vous avez besoin.

wisp-mcp doctor && wisp-mcp compatibility
ÉTAPE 06

Donnez à l’IA une règle de travail simple

Demandez-lui d’inspecter avant de modifier, de sauvegarder avant une opération risquée, de faire le plus petit changement possible puis de relire l’état et les logs.

Guide de reconnaissance détaillé
Contrôle des capacités

Le serveur MCP décide ce que l’IA a le droit de faire.

Changer de client IA ne doit pas élargir silencieusement les permissions. Les capacités de mutation sont explicites et le destructif garde un interrupteur séparé.

Usage normal

  • Lire état, ressources, logs et fichiers
  • Modifier des fichiers avec vérification SHA-256
  • Exécuter des commandes console si autorisé
  • Redémarrer ou créer une sauvegarde si autorisé

Destructif, volontairement séparé

  • Suppression de fichiers ou sauvegardes
  • Restauration sur les données live
  • Suppression de base ou rotation de credentials
  • Force-kill et opérations équivalentes
Questions fréquentes

Les points qui bloquent le plus souvent.

Est-ce lié à un hébergeur précis ?

Non. Wisp MCP cible l’API Client WISP. Si votre hébergeur fournit un panel WISP et un token Client API, le même connecteur s’applique.

Dois-je donner un accès SSH complet à ChatGPT ?

Non. Le but est justement de limiter l’IA à la surface exposée par WISP et aux capacités MCP activées.

GitHub est-il obligatoire ?

Non. GitHub est utile pour conserver code, règles, roadmap et handoff. La connexion WISP fonctionne indépendamment.

Pourquoi ne pas activer toutes les permissions ?

Une permission inutile augmente la portée d’une erreur. Commencez en lecture seule, puis ouvrez seulement ce qu’exige la tâche.

Prêt à connecter votre panel ?

Commencez par la checklist, puis laissez les diagnostics confirmer chaque couche.
