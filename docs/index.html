Manage Wisp game servers through MCP.

Wisp MCP exposes the Wisp Client API as secure MCP tools for server status, files, logs, console commands, power, backups, databases and diagnostics. It works with compatible Wisp hosts such as VeryCloud.

View on GitHubLatest release

Game-server focused

Use the same integration for Rust, Minecraft and other game servers hosted through Wisp.

Safe by default

Read-only first. Console, file changes, power, backups and destructive actions are separate capability gates.

Local or remote

Use stdio locally, Streamable HTTP remotely, or keep the service private behind a secure outbound tunnel.

One-line VPS install

On Debian 12 or Ubuntu 24.04+:

curl -fsSL https://raw.githubusercontent.com/BreezeDelegate/wisp-mcp/main/install-vps.sh | sudo bash -s -- --with-openai

VeryCloud Wisp MCP

VeryCloud users can set WISP_PANEL_URL=https://panel.verycloud.fr, add a Wisp Client API token, run wisp-mcp doctor, and start in read-only mode. The repository includes a dedicated VeryCloud guide.

Discover and install

Releases include wheel, source archive and MCP Bundle artifacts. Wisp MCP is published in the official MCP Registry as io.github.BreezeDelegate/wisp-mcp.
