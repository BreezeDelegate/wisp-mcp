Machine toujours allumée

Prépare un petit VPS Linux.

Wisp MCP est léger et peut tourner sur une petite machine. Le serveur de jeu peut rester chez ton hébergeur actuel : le VPS sert uniquement au MCP et au tunnel privé.

Terminal

Installe Wisp MCP en une commande.

L’installateur crée un utilisateur système dédié, installe Wisp MCP et le tunnel OpenAI, puis te demande l’URL du panel et le token directement dans le terminal.

Sur ton VPS
curl -fsSL https://raw.githubusercontent.com/BreezeDelegate/wisp-mcp/main/install-vps.sh | sudo bash -s -- --with-openai
  1. 1Colle la commande et laisse l’installateur terminer.
  2. 2Saisis le token WISP uniquement quand le terminal le demande.
  3. 3Ne continue que lorsque le diagnostic affiche Wisp API: OK.
Tunnel privé

Relie maintenant le VPS à ChatGPT.

Le tunnel est sortant : tu n’ouvres pas de port MCP public sur le VPS.

  1. 1Dans OpenAI Platform, crée ou sélectionne un MCP Tunnel.
  2. 2Crée une clé runtime pour le tunnel avec les droits nécessaires Tunnels Read + Use.
  3. 3Sur le VPS, lance la commande ci-dessous et saisis l’ID du tunnel et la clé uniquement dans le terminal.
  4. 4Dans ChatGPT, crée l’app MCP en mode développeur, choisis Tunnel, scanne les outils puis enregistre l’app.
Sur ton VPS
sudo wisp-mcp-openai-setup

Routines IA

Ajoute trois Skills pour garder l’IA propre.

Copie chaque instruction dans ChatGPT et demande-lui de créer le Skill. Ils servent à conserver le contexte dans GitHub, à travailler prudemment avec Wisp et à terminer chaque changement avec une vérification.

Project Memory

Règles, roadmap, décisions et handoff restent versionnés dans le dépôt privé.

Wisp Safe Ops

Inspecter avant de modifier, sauvegarder avant le risque, vérifier après chaque action.

Release Guard

Tests, état réel, rollback et handoff avant de considérer un lot terminé.

Les Skills sont recommandés, pas obligatoires pour utiliser Wisp MCP. Tu peux aussi les créer plus tard.
